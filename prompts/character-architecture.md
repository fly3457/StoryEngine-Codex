# Prompt: Character Architecture

## Instructions for Codex

Phase 3 begins when the user approves the world files.

### Step 1: Read Context

Read PROJECT.md, all world/ files (including rules and timeline), characters/cast.md,
characters/_TEMPLATE.md, existing relevant profiles, and continuity/changelog.md.
Record missing reads; do not rely on chat memory or silently override established facts.

### Step 2: Build the Cast

Populate characters/cast.md with the full cast, roles, one-line descriptions, and
key relationships. Create each major character's own Markdown profile from the
original template. Preserve every template category: identity, physical description,
backstory, psychology, arc trajectory, Voice DNA, relationships, key scenes, secrets,
and notes. Include motivation, want/need, flaw/fear/coping mechanism, starting/midpoint/
ending states, speech patterns, vocabulary, verbal tics, internal voice and sample dialogue.

Read existing profiles before adding a character; align relationships and knowledge
with the world and timeline. Proposed future arcs are plans, not accomplished facts.
Present unresolved creative alternatives instead of silently deciding important Canon.

### Step 3: Review Gate

Present the cast and profiles, iterate until approved, and record approval in the
changelog. Update PROJECT's Characters status, then proceed to Phase 4: Structural Outlining.
