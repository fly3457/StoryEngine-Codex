# Prompt: Style Calibration

## Instructions for Codex

Phase 5 begins when the user approves the outline.

### Step 1: Read Context

Read PROJECT.md, key character profiles (including Voice DNA), the relevant outline,
style/voice-guide.md, style/motifs.md, style/samples.md, and continuity/changelog.md.
Record missing reads. Preserve any voice decisions already approved by the user.

### Step 2: Offer Three Tonal Samples

Write three sample passages, 300–500 words each, in different tonal registers:
- Option A: more literary, dense, interior.
- Option B: more cinematic, propulsive, visual.
- Option C: a hybrid or alternative approach.

Save the candidates in style/samples.md as explicitly unapproved options and present
them for selection or requested modifications. They demonstrate voice; invented
sample events do not become established story facts or close plot threads. Record
this no-Canon-change result and the calibration work in the changelog.

### Step 3: Codify the Chosen Voice

After the user selects or adjusts the voice, populate style/voice-guide.md with POV,
narrative distance, tense, sentence rhythm and length tendencies, paragraph rhythm
and length, metaphor and description density, dialogue style, exposition strategy,
pacing philosophy, and what the voice does NOT do. Retain the original template fields.
Populate style/motifs.md with recurring images, symbols, and thematic echoes.
Save the approved 300–500 word sample in style/samples.md under Approved Sample.
Remove unselected candidate prose from that reference file and log the selection;
do not leave unapproved prose masquerading as the active reference.

### Step 4: Review Gate

Present the voice guide, motifs, and selected sample. Record actual approval and
update PROJECT's Style calibrated status. Only start Phase 6: Iterative Drafting
when the user approves the style and directs drafting. An explicit existing direction
is sufficient; do not request the same permission again.
