# Prompt: Conception

## Instructions for Codex

Phase 1 begins when the user shares an idea, premise, or "what if" scenario.
Read PROJECT.md and continuity/changelog.md before making story decisions. If
STORY_SEED.md exists, read it as user-supplied source material and preserve its
constraint levels; it is not Canon or evidence that this Gate passed. If existing
Canon is present, preserve it; a new idea is not permission to reset a story.

### Step 1: Clarify the Idea

Ask about genre, tone, target length, core themes, and intended audience. Use what
the user or STORY_SEED.md has already supplied; ask only for unresolved creative choices. Offer
options and tradeoffs without taking the director's decision away from them.

### Step 2: Write PROJECT.md

Populate its original fields: Working Title, Logline, Premise, Genre / Subgenre,
Core Themes, Target Length, Comparable Works, Current Phase, and Status. Preserve
user-supplied tone/audience decisions as notes in PROJECT rather than chat-only state.
Use a working title when final naming is undecided; mark open choices honestly.
Do not treat bracketed examples or illustrative comparison titles as user approvals.

### Step 3: Review Gate

Present PROJECT.md for approval and iterate as directed. Record actual approval
and its scope in continuity/changelog.md, update PROJECT's existing checklist,
and only then proceed to Phase 2: World Building. Do not invent approvals or
advance because the scaffold has been initialized.
