# Security Policy

[简体中文](SECURITY.md) | [English](SECURITY.en.md)

## Supported versions

This project does not yet publish long-term support branches. Security fixes target
the latest revision of the default `main` branch. Older commits and user-modified
copies are not maintained separately.

## Report a vulnerability privately

Use GitHub
[Private vulnerability reporting](https://github.com/fly3457/StoryEngine-Codex/security/advisories/new).
Do not disclose an unpatched vulnerability in a public issue, discussion, or pull
request.

Please include, when possible:

- the affected commit, version, script, or file;
- reproducible steps or a minimal proof of concept;
- practical impact and exploitation conditions;
- known mitigations;
- any disclosure deadline you are working under.

Maintainers aim to acknowledge a report within seven days and will coordinate a fix
and disclosure timeline after reproduction and impact assessment. This is a target,
not a service-level guarantee.

## Examples of security issues

Private reports are appropriate for command injection, path traversal, unsafe file
replacement, dependency supply-chain risk, credential disclosure, or behavior that
permits unauthorized reading or writing of story files.

Literary quality, model hallucinations, prompt preferences, and ordinary feature
requests are not security vulnerabilities and may use a normal issue. If a report
involves private or copyrighted manuscript material, remove the prose and personal
information and provide only the smallest useful reproduction.
