# 最小状态示例：闭馆前的信

这是模板表达能力的示例，不是已执行的八阶段创作或用户批准的小说。包含一个地点、
两个人物、一封信、一个秘密、一条计划中的线程和一个 Scene Card；没有章节正文。
所有状态都是人工提供的 fixture seed，PROJECT 的审批项保持未勾选。

在一个**全新的完整仓库副本**里，把本目录的 PROJECT、world、characters、outline、style、
continuity 和空 drafts 内容放到该副本根目录；保留副本自带的 AGENTS、docs、prompts、scripts
与 build-docx.js。不要覆盖已有故事，也不要在原仓库混用示例和活动状态。
然后在 Codex 中打开副本根目录，要求先审阅示例 PROJECT，再依次走 Review Gate。

style/samples 中的短句只是未批准的占位示例；到 Phase 5 仍必须生成原协议要求的三份
300–500 词候选样稿。Scene Card 的 500 words 是上游字段的示例值，不表示 500 个中文字。
