# Minimal State Example: The Letter Before Closing

[简体中文](README.md) | [English](README.en.md)

This demonstrates the template's state model. It is not the result of an executed
eight-phase workflow or a user-approved novel. It contains one location, two
characters, one letter, one secret, one planned thread, and one Scene Card. It has no
chapter prose. Every value is a manually supplied fixture seed, and the approval
boxes in `PROJECT.md` remain unchecked.

Use this example only in a **fresh, complete copy of the repository**. Copy this
directory's `PROJECT.md`, `world/`, `characters/`, `outline/`, `style/`, `continuity/`,
and empty `drafts/` state into the root of that copy. Keep the copy's own `AGENTS.md`,
`docs/`, `prompts/`, `scripts/`, and `build-docx.js`. Do not overwrite an existing
story or mix example state with the active root story. Open the fresh copy in Codex,
review the example `PROJECT.md` first, and then proceed through each Review Gate.

The short passages in `style/samples.md` are unapproved placeholders. Phase 5 must
still produce the three 300–500-word candidate samples required by the protocol. The
Scene Card's 500-word value is an upstream field example, not a 500-Chinese-character
target.
