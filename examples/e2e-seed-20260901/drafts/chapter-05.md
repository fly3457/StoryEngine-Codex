# 第五章　旧坐标

防水图袋被贴在互助会窗上，所有人都能看见那条向下折断的曲线。

高岩在玻璃内侧压了四枚图钉，右下角盖着登记副本章。窗外挤着停班矿工，呼出的白气一层层覆上玻璃，又被袖子擦开。曲线最陡的部分就在每个人眼前，旁边是林栖三个月前写下的日期。

“你那时就知道。”高岩说。

“知道十三到十七号不能再按原负荷开。”

“为什么今天才让大家看全？”

林栖把原件从矿务室带来，纸角与副本完全重合。她可以解释还缺两次复测，可以解释停矿会先断谁的工资，也可以说周砺请求等待替代方案。每一项都是真的。叠起来仍是三个月。

“他要求等。”她说，“我接受了。我没有改数据，也没有把完整图交给该承担后果的人。这部分是我的。”

窗外有人骂了一句。高岩没有替她挡。

“你怕我们逼你签复工？”

“我怕一公开，矿只剩开和关两个答案。”林看着玻璃上的曲线，“结果是我替你们保管了问题。保管太久。”

十三点十九分，议事会的紧急复工单送到互助会。纸上要求开启“十一号低风险回采段”，用以维持安全短班产量。林只看了一遍便发现坐标不对：单上写的是上一版测绘基点，向东偏了四十六米。按新坐标换算，那不是十一号安全段，而是十四号红区的旧支巷。

“谁在入口？”她问。

高岩抓起值班表。“两个维修工，检查风门和主支护。没有采煤班。”

林把复工单折进胸袋，和那张未签许可放在一起。“叫他们撤。现在。”

从矿工区到深层入口，卡车沿固定路线要二十分钟。司机没有抢过结冰弯道，只在直道把车稳稳压到限速线，二十分钟后停在警戒栏外。林跳下车时，井口电话正从十四号转接台传来断续的回音。

“两人已往外走。”值班员说，“风门卡住，他们在手动——”

话音被地下的一声闷响截断。

不是爆炸。第一下来自深处，频率低，脚下铁轨只抬了一点。两秒后，空气从井口推出，煤尘贴着顶棚冲过警戒线。林看见右侧支柱先向内弯，再弹回；载荷没有越过主入口极限，但十四号里面至少有一段顶板落了。

“趴下！”

第二股冲击带着碎石。两名维修工刚越过风门，一人被掀到轨边，左臂压在工具箱下；另一人撞上支柱，弯腰咳不出声。没有第三个人。林先数完，才允许自己跑过去。

高岩和救护员抬开工具箱。骨头没有穿出皮肤，指尖还有颜色。另一人的呼吸浅而快，胸口右侧起伏比左侧小。林不会替徐澄下诊断，只让人保持侧卧、不要喂水。担架抬走时，十四号又落下一小片岩，声音隔着封闭风门传来。

红区里没有采煤班。

这句话救了二十八个人，也没有让眼前两个人免于受伤。旧坐标把已经停止的危险重新写成了低风险；如果那张单早一个班次到达，入口外不会只有维修工。

十五点四十分，林让人在矿井入口架起测绘板。矿工、港务员和议事会记录员都在。她依次挂出原始曲线、三个月前的公开版、Day 0 复测和那张错位四十六米的复工单。

“删去的区间在这里。提出等待的是周砺，接受等待的是我。今天这张单用了旧基点，签发部门要查；但它能被当成低风险，是因为完整版本没有公开。”

议事会记录员说复工单还在“征询”，并非最终许可。林把纸翻到背面，那里已有调班时间和设备编号。绞车已经预热，维修工已经进场，一个没有最终盖章的坐标仍然移动了人。她没有报抄写员的名字，只要求封存签发链、测绘底版与送达时间。把错误推给桌前最后一双手，不会让旧基点自己走进表格。

有人问：“所以矿全关？”

“十三到十七号永久停。不是全关。”

“剩下的够我们吃饭？”

林指向配给栏。Day 8 实存煤三百六十一、粮二百零九。短班每天补三单位煤，供暖每天仍净少五。数字没有承诺工资，也不能把两名伤者抬回受伤之前。

“按现在这个数，只留两条巷道。”她在新图上划出六号与九号，“每班不超过三小时，班前复测，任何支护位移超过六毫米立即停。其余人不是回家等。”

高岩接过粉笔，在两条线旁写下人数。支护队先加到十二人，修矿工区到诊所的供暖管线；另一队去旧港做栈桥防冻和潮尺保护。采煤技能能转到顶撑、焊接和绞车维护，但工资口径必须重新谈，不能把转岗写成无薪互助。

后排有人问，防冻队的工资按矿班还是救济工。林没有替议事会定价，只把问题写到图旁：危险津贴不得因换岗消失，短班损失另列，名单由互助会核。她能确定的是载荷与人数；确定不了的部分也必须留在人人看得见的位置，而不是再收进某个人的抽屉。

“谁来验你画的安全线？”他问。

林把原始记录推到板沿。“互助会留一份，议事会一份，矿务室一份。每次复测三方都签。我的名字也在延迟说明上。”

人群没有原谅她。有人把三个月重复了两遍，有人只盯着两条还能工作的巷道。高岩把防水图袋从窗上取下，没有还给林，转手交给登记员复制第三份。

十七点三十六分，入口电话响了。林接起时，徐澄的声音被线路里的杂音削得很平。

“两个人都能救。一个左臂骨折，一个肺挫伤。”徐说，“我现在开始处理。按现有可用止血和抢救用品，做完这两例，只够再处理三次同等事故。”

林看着还没干透的两条安全线。六毫米、三小时、三次。

第一次，矿区所有人都能看见这些数。也第一次，没有一个数能藏住是谁让它拖到了今天。
