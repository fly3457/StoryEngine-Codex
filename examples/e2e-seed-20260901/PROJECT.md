# PROJECT — 《灰港》

## Working Title
《灰港》

## Logline
严冬封港前二十一天，掌握矿脉真相的总工程师、查出污染药品的医生、挪用救济款救急的市长与经营暗线航路的走私协调者，必须在公开秘密可能摧毁秩序之前，把灰港从对煤矿、隐瞒与人情网络的共同依赖中改造成一个还能活下去的共同体。

## Premise
灰港是一座靠老矿供暖、靠旧港换粮的北方小镇。主矿脉已经接近安全寿命终点，诊所仅存的药品中又有一批确实受到污染；与此同时，一笔未公开审批的救济款曾被市长转去购买急救药，而经手的夜潮网络正是议事会准备清剿的对象。四名各自只掌握部分真相的人必须在二十一天倒计时里决定何时说出什么、愿意失去什么，并建立一套不靠某个人继续隐瞒才能运转的新秩序。

## Genre / Subgenre
现实主义政治悬疑 / 生存危机 / 群像伦理剧

## Core Themes
- 共同体生存不能靠制造一个方便的恶人来解决结构性依赖
- 真相若没有可承受的公开方式，也可能成为摧毁秩序的力量
- 私人承诺与公共责任既会冲突，也可能成为新制度的起点

## Target Length
E2E 短中篇测试；8 章；12,000–15,000 个汉字。

## Comparable Works
以《切尔诺贝利》的制度性灾难压力、《十二怒汉》的立场交锋和现实主义港镇报道的克制质地作为气氛与结构参照；不模仿具体情节、人物或句法。

## Tone / Audience
- **Tone:** 克制、紧张、道德暧昧；危险先通过物资、空间与身体后果呈现，再进入人物认知。
- **Audience:** 成年大众读者；可接受制度细节、资源计算、有限暴力和没有廉价洗白的代价式结局。
- **Content Boundaries:** 不使用真实人物或真实政治组织；不把任何群体写成天生邪恶。
