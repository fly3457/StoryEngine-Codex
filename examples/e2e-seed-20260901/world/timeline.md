# Timeline

## Before the Story
| When | Event | Significance |
|------|-------|-------------|
| 十七年前 | 灰港扩大深层矿区，以煤换粮和港口维修物资 | 建立今日无法迅速拆除的结构性依赖 |
| 上一场严冬 | 正式药品供应中断；陈默潮经夜潮网络送药，徐澄先救人后追查来源 | 徐澄欠陈人情，但不等于信任所有夜潮药品 |
| 三个月前 | 林栖核对衰减曲线，确认主矿脉安全寿命远低于公开报告 | 她保存原始地质记录，尚未公开完整结论 |
| 四十天前 | 周砺批准把部分救济款转作未公开审批的紧急药品采购，陈默潮经手 | 周、陈知道账目秘密；采购曾救急，也留下合法性风险 |
| 七天前 | 一批新药经旧港进入诊所；封条与旧批次不同 | 污染批次进入 48 个治疗单位的库存 |

## Story Timeline
| Chapter | When | Event |
|---------|------|-------|
| 01 | Day 0，上午 | 林栖拒签深层矿继续满负荷生产的安全许可，并把原始记录送出矿井 |
| 02 | Day 1，下午 | 徐澄检测新药，确认污染并封存 17 个治疗单位；诊所出现供应缺口 |
| 03 | Day 3，傍晚 | 周砺面对减产、配给与审计传闻，提出延迟公开并试图争取七天窗口 |
| 04 | Day 5，夜 | 陈默潮的补给船被扣；四方首次同桌，矿寿命与污染药同时进入公共争议 |
| 05 | Day 8，午后 | 林栖公开完整地质记录；矿工停工谈判，旧巷道局部坍塌证明风险不可拖延 |
| 06 | Day 11，夜 | 徐澄在诊所资源危机中建立公开分诊与批次检测，迫使各方共享真实库存 |
| 07 | Day 15，下午 | 周砺在公开审计会上承认救济款去向，交出单方许可权，四方拟定冬前协议 |
| 08 | Day 20 夜至 Day 21 清晨 | 陈默潮完成最后一趟许可补给；多方签署改革协议，严冬封港开始 |
