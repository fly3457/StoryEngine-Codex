# 第五章　二十六米黑水

安全绳扣上陈渡腰带时，他想起十五岁那年涵管里抓不到任何东西的手。

那年他被回水推走三米，头顶全是水泥，父亲在外面喊到失声。此后他照样下江游泳，却再没进过一条看不见天的管子。

“我进去会慌。”陈渡说。

许葵正检查他右膝，抬头看了他一眼。“说出来就少算一个突发情况。”

墙上应急柜里有一根三十五米救生绳。方素梅和江澜共同握主绳，陈渡的配送捆绳把他与后面的马成业连在一起。戚长林坐在管口，先指眼睛，再指绳：一记重拉是停，两记是放绳，三记是外闸已开、准备返回。陈渡逐个复述，让戚看清嘴形。

戚不放心，又让他现场打了一遍腰结。陈渡第一次收得太紧，戚摇头；第二次留出两指宽，老人才拍了拍绳扣。马成业把受伤的右手吊在胸前，左腕也系一道活扣。两个人若有一个失去意识，后面的人不能自行解开，也不能被前面的人拖进外闸。

“谁都别凭感觉松手。”江澜说。

“知道。”陈渡把主绳递进方素梅掌心，“我这回把命交给两份文件的作者。”

“一份文件。”方素梅说，“另一份是名单。”

他没有笑，伏身钻进圆管。

水没到胸口，管顶只在后脑上方留出一掌。陈渡用左肘和膝盖往前挪，右膝每压一次都钝痛。小手电绑在手背，光照出粗糙水泥、旧裂纹和漂过来的白色菌膜。马成业在身后，右掌举出水面，左手拖着戚长林的短柄扳手。

前六米还有夹层的冷白光。第七米，身后只剩一个硬币大的洞。水声把人说话压回嘴里。

管壁每隔两米有一道接缝，陈渡就把它当路标。冷水从衣领灌进去，右膝在粗糙管底拖过，疼痛反而帮他确认自己还在往前。他不能转身，只能从捆绳的松紧判断马成业有没有跟上。那个人也把自己的命交了出来，重量隔着一根旧配送绳落在他腰后。

陈渡开始数：一个外卖取餐点，两百米；下一个红灯，四十秒。把二十六米拆成他熟悉的路程。数到十一时，一股回流从前面涌来，小手电浸进水里，立刻黑了。

他停住，肩胛顶着管壁，呼吸一下比一下浅。十五岁那只抓空的手从黑暗里回来，替他攥紧喉咙。

腰间的主绳绷住。没有往回拽，也没有松掉。方素梅和江澜在二十米外告诉他：我们还在。

马成业用扳手敲管壁，一下，又一下。陈渡摸到手电开关，甩出积水，微弱的光重新亮起，只剩一格。

“继续。”他说。

他们在第十七米的高点换气。马成业靠着管壁，冷得牙齿相碰。“八月十八，井盖四个点是我焊的。今天五点五十，油管也是我割的。周竞说不割就别结七月工资。”

“你现在说给我听，有什么用？”

“你让我说全。”

“出去以后也这么说。”

马成业低下头，额头碰在水泥上。“先出去。”

二十六米尽头是一间只能弯腰站立的闸室。外翻板没有焊死，却被芦苇根、塑料布和淤泥塞得严实。江水从缝隙里一呼一吸，像另一边有一只湿肺。

陈渡把救生绳绕过闸框，马成业用扳手撬开下缘。第一次发力，马右掌的敷料便浸红；第二次，陈渡右膝一软，整个人跪进冷水。塑料布只松了一角。

“然后呢？”陈渡喘着气对那扇门说，“你也等通知？”

他把腰背抵住翻板，马用扎带把一束芦苇根收紧，两人同时发力。淤泥先冒出一串恶臭气泡，接着整块塌下去。两人的腰背和管内积水把翻板顶开不到半尺，湍流从他们腿边卷过。

够了。不是逃生的宽度，却够排水。

陈渡向主绳连拉三次。远处回了三次。有人接到他们的信号。

他没有看见管口的人，却能从绳上传来的细小停顿认出他们的动作：先是方素梅确认次数，接着江澜收紧余绳，最后有人把成功告诉听不见的戚长林。过去他最讨厌“大家”这个词，因为说这个词的人通常不用报名字。此刻绳子另一端不是大家，是六双具体的手。

回程时水流方向变得混乱，他们只能贴着绳走。小手电又灭了一次，陈渡没有停；那根绳已经不再像约束，更像一条能摸见的路。爬出管口时，他和马都在发抖，肘部磨破，马的敷料完全湿透。许葵把反光毯披过来，陈渡却先听见夹层另一头的争吵。

周竞正抓着唐晓满的防水袋挂绳。“外援要准确情况。你拿剪过的视频误导他们，会耽误所有人。”

“松手。”唐两手护着袋口。

“我只是统一——”

陈渡挤过去，扣住周竞手腕。周竞脚下不能受力，身体一晃，手机从防水袋滑出，砸在钢格板上。屏幕裂成一张蛛网，角上的摄像头也出现白纹。

所有人都静了半秒。

周竞先说：“不是我摔的。”

唐晓满跪下捡起手机。屏幕还能亮，触控却断断续续。她没有哭，也没有先试摄像头，而是从挂绳折缝里抽出一张指甲盖大小的存储卡。

“你上次要抢以后，我就拿出来了。”她对周竞说，随后转向方素梅和许葵，“你们两个看见了。原片在这里，卡还是我的。谁拿、谁复制，先问我。”

两人分别说“看见”。马成业裹着新纱布，凑近破裂屏幕，确认录像日期、四处焊点和自己站的位置。陈渡没有要求唐把卡交出来。他只让她把挂绳重新塞进衣服里。

外闸已开，他们还有内阀和油管。

马成业用备用胶管跨接断口，两只管箍一前一后锁住。戚长林靠触摸检查接头，向江澜做了一个先试发动机的手势。旁通尚未切换，离合器保持断开，谁也没有让泵带水。

马按下启动。

柴油机咳出第一声，震得钢座发颤，随即熄火。断口接头处喷出一股带油味的细雾，在手电光里短暂地亮了一下。
