# Timeline

## Before the Story
| When | Event | Significance |
|------|-------|-------------|
| 1998 | 鹭湾二号排涝站投用，旧检修旁通与堤外闸室建成。 | 建立老机械结构与戚长林的工作记忆。 |
| 2022-11 | 溪津市公布七号码头滨江更新计划“澜庭”。 | 拆迁与防洪改造被捆绑推进。 |
| 2024-05 | 东衡设计院提交排水迁改图；江澜在包含“施工期临时封头”的会签页签字，同时在内部意见中要求汛前拆除并保留二号站。 | 江澜的责任与异议同时留下文件痕迹。 |
| 2025-03 至 2026-07 | 方素梅负责入户签约；居民对补偿、租户安置与泵站安全多次争执。 | 建立社区内部的不信任与方素梅的内疚。 |
| 2026-06 | 市级系统把二号站标注为“待迁改备用”，社区纸质避险图未更新。 | 造成灾时信息错位。 |
| 2026-08-18 | 周竞为防基坑进水，要求分包班组保留主渠封头并点焊竖井顶盖。唐晓满从围挡外拍到部分施工。 | 核心违规行为与影像证据产生。 |
| 2026-08-20、08-28 | 戚长林两次报告封头逾期和泵站无法测试，未获实质处理；他把照片发给已离职的江澜。 | 促使江澜回溪津并携带旧图、投诉回执。 |
| 2026-09-01 17:50 | 暴雨升级，楠江水位快速上升；马成业奉周竞口头命令进入泵站割断应急泵进油软管，随后因外部塌方和恐惧藏入工具间。 | 第八人先于其余人进入，泵机被人为失能。 |
