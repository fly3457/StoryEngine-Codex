# PROJECT — 《水位线以下》

## Working Title
《水位线以下》

## Logline
一场破纪录暴雨把八个人困进一座被地产工程暗中废弃的排涝站；在水位淹顶前，他们既要找出泵机为何失效，也要决定是否把足以追责、却会撕裂临时同盟的证据一起带出去。

## Premise
虚构的溪津市正经历旧码头社区拆迁与滨江地产开发。暴雨当夜，七名背景、利益与立场各异的人被困在鹭湾二号排涝站，监控却显示有八个人进入；第八人的出现揭开一条被人为封死的排水通道，也迫使曾参与设计变更的工程师江澜面对自己的沉默。救援迟迟不到，水位不断上升，他们只能把工人经验、居民记忆与专业知识拼成一条生路，同时保存能够证明灾害并非纯属天灾的材料。

## Genre / Subgenre
现实主义悬疑 / 密闭空间生存 / 群像 / 社会冲突

## Core Themes
- 灾难并不会自动抹平阶层，合作必须经过艰难协商
- 沉默、程序与“临时措施”如何共同制造可否认的责任
- 文件、见证与公共记忆能否对抗权力对事故的改写
- 个人赎罪不能代替集体追责，但可以成为行动的起点

## Target Length
短中篇测试；8 章；最终正文约 10,000–15,000 中文字，目标约 12,500–13,500 中文字。

## Comparable Works
氛围参照《隧道》的受困压迫感、《十二怒汉》的群体争执结构与现实主义灾难报道的克制质地；只用于节奏和伦理张力校准，不模仿具体情节或句法。

## Tone / Audience
- **Tone:** 冷峻、紧迫、克制；允许短暂幽默来自人物摩擦，不使用猎奇血腥。
- **Audience:** 成年大众读者；能够接受工程细节、道德灰区与开放但完整的社会后果。
